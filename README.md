# hypaTorch
<p align="center">
<b>Highly Abstract Compound Networks in PyTorch</b>
</p>

This python package provides a flexible and comprehensive framework for creating compound PyTorch models in an abstract manner.

## Installation

```bash
uv add hypatorch
```

## Documentation

How to declare a model, write a submodule, and configure losses, optimizers and
the trainer: [`hypatorch/agent_docs/`](hypatorch/agent_docs/OVERVIEW.md). How the
machinery works underneath: [`docs/`](docs/README.md).
